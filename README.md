# 🎮 Tic-Tac-Toe Game

A simple console-based Tic-Tac-Toe game built with **Python** using **Object-Oriented Programming (OOP)** principles.

---

## ✨ Features

- 👥 Two-player gameplay
- 🔤 Custom player names
- ❌⭕ Custom symbols
- ✅ Input validation
- 🏆 Win detection
- 🤝 Draw detection
- 🔄 Restart game
- 🧩 Clean OOP design

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/marwan68/Tic-Tac-Toe.git
```

Go to the project folder:

```bash
cd Tic-Tac-Toe
```

Run the game:

```bash
python main.py
```
